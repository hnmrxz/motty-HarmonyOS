feat(harmonyos/rdp): RDP 会话视图(打开 rdp 主机 -> 大画面+刷新+关闭) + 用例 PASS

实现:
- 分流: openSession() 里 h.proto==='rdp' -> 不再建 SSH 会话, 直接 openRdpSession()
- 连接: 取主机地址/端口(默认3389)与内存凭据 -> mottynapi.rdpRender(host,port,user,pass,cb)
- 画面: 回调里 rdpFrameSeq() 有帧则 rdpWriteBmp(cacheDir/rdp-session.bmp) -> Image('file://'+path+'?v='+now)
- UI: rdp/session-view 覆盖层: session-title / session-frame / session-refresh / session-close / session-status
- 空态: 无帧时显示 rdp/session-placeholder("正在获取画面…")

用例 rdp.session-view PASS: 起内嵌 shadow 服务端(13389) -> 建 proto=rdp 主机 -> 点打开 ->
  出现 "RDP 会话：rdp-sess" 与画面节点 -> 状态行出现 render:/bmp seq=
