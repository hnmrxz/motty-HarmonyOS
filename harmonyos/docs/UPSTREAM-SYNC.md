# 上游同步核对（t8y2/motty）

## 结论
本仓库 fork 之后，`upstream/main` 已前进 **114 个提交**（其中约 62 个与 UI/workbench 相关、约 30 个 `feat`）。
**不建议直接 merge**：上游是 Go 桌面端，合并只会把不相关代码带进来；正确做法是**逐条核对是否有"用户可见功能"需要在本端补齐**。

核对命令：
```bash
git fetch upstream
git log --oneline HEAD..upstream/main
git log --oneline HEAD..upstream/main --grep="^feat"
```

## 与我们当前 UI 差异最相关的三条（来自截图核对）
1. **工作区 = 布局模板**（1/2/3 列、主栏+右侧、主栏+底部、标签切换、最多 12 个终端、广播输入）
   —— 我们的"工作区"只是标签列表，语义完全不同，属于**大改**。
2. **顶栏标签 + 三色状态点 + 后台输出提醒开关** —— 我们有未读圆点骨架，缺三色语义与开关。
3. **监控页**（CPU/内存/磁盘/网络 + 采样间隔 + 保留时长 + 简洁/详细）—— 我们**整页缺失**。

## 建议顺序（成本/收益）
1. 监控页（缺栏目，中等成本）
2. 顶栏标签 + 状态点 + 后台输出提醒设置（小改，视觉差异明显）
3. 设置两栏分类导航（小改）
4. 已知主机改表格页（中等）
5. 工作区布局模板（大改，最后）
