# 主题与配色（Dark / Light）

## 怎么工作
所有"表面 / 文字 / 边线"颜色都通过 `th(dark)` 取值：

```ts
private th(dark: string): string {
  if (this.themeMode !== 'light') { return dark; }   // 深色：原样返回
  ...                                                 // 浅色：映射到浅色值
}
```
调用点写的是**深色基准值**，例如 `fontColor(this.th('#E8EAED'))`。

- 彩色强调（绿 `#2F6F4F`/`#3DDC97`、蓝 `#1A6DD0`、红 `#C62828`、紫 `#6A1B9A`、黄 `#E0A458`）**不参与主题**，两套主题共用
- 终端区域永远是深色（`#000000` 画布、`#1E1E1E` 面板、`#D4D4D4` 文字），不随主题变化
- 设置项：`settings/theme-dark` / `settings/theme-light`，存 DB `ui_state.themeMode`

## 自动化保障
| 工具 | 作用 | 当前 |
|---|---|---|
| `tools/check-theme.py` | 近灰颜色必须走 `th()`（彩色除外，白名单见脚本注释） | `0` 违规 |
| `tools/check-contrast.py` | 深浅两套「文字 × 表面」WCAG 对比度 ≥ 3.0 | 深色最差 3.05、浅色最差 3.42 |

## 已知边界（诚实）
- **像素级目视未做**（无设备）：浅色下个别白底面板/终端区的观感、禁用态与悬停态对比度需人工确认
- 终端工具条的 `#E6E6E6/#1A1A1A` 历史浅底按钮**刻意不跟随主题**（待目视后再决定）
