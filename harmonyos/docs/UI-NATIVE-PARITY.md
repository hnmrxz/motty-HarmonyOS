# 原生 motty UI 观察清单（用于 1:1 对齐）

> 来源：用户提供的原生版本截图（2026-11-13）。**这是对齐基准，不是我们的实现**。
> 我们的差异逐条列在每节末尾，未达成的写"未做"。

## 1. 窗口顶栏（最上面一行）
- 左：九宫格 + `+`
- 中：**会话标签页**（图标 + 标题 + 状态点：绿=正常/黄=异常；每个标签有 × 关闭）+ `+` 新建
- 右：刷新/排序、分栏、终端、搜索、AI(✳)、GitHub、设置、窗口按钮（最小化/最大化/关闭）

**我们**：顶栏是图标工具栏，**标签栏在内容区内部**（第 2 行）；缺 GitHub 按钮、缺状态点。
→ 待做：把标签移到顶栏行、给标签加状态点。

## 2. 左侧导航
主机 / 工作区 / **监控** / 会话日志 / 密钥链 / 跳板路由 / 端口转发 / 已知主机 / 快捷命令 / 笔记
底部固定：本地终端 / 设置

**我们**：缺 **监控** 整个二级页面（未做）。

## 3. 主机页
- 大搜索框「搜索主机或 ssh user@hostname…」+ 右侧「连接」按钮
- 分组 chips：全部(6) / 个人(4) / 求是物业(2)
- 右上：导入/导出、新建主机；再右：‹ › 翻页、网格/列表切换、排序、滑块（视图选项）
- 列表：勾选框 + 图标 + 名称 + 用户 + 标签 + 地址 + 状态「未连接/已连接」+ 行尾 ⋯

**我们**：有搜索、chips、导入导出、新建、网格/列表、排序、视图选项、勾选、⋯菜单；
缺「连接」按钮（用 ssh 语法直接连）、缺行尾连接状态文字、缺翻页。

## 4. 新建主机对话框（原生）
- 顶部协议分段：**SSH / Telnet / 串口 / VNC / RDP**
- 名称 + 颜色圆点（预设色 + 自定义）
- 地址 + 端口
- 用户 / 认证方式（自动…）/ 密码（可见性切换）
- 分组 / 标签
- 图标 / 文件传输协议（自动 / SFTP / SCP）
- 出站代理（配置） / 跳板路由（配置，保存主机后可加）
- 高级选项（折叠）
- 底部：测试连接 / 取消 / 添加主机

**我们**：有名称/地址/端口/用户/密码/分组/标签/图标/协议(SSH·RDP·VNC)/颜色；
缺 Telnet、串口、认证方式、文件传输协议、出站代理、跳板路由、高级选项、测试连接按钮。

## 5. 已知主机页（原生）
- 标题 + 说明；搜索框（主机/类型/指纹/注释）
- 右上：刷新 / 重新信任 / 删除
- 表格列：行、主机模式、标记/哈希、密钥类型、指纹、注释（每行勾选框）
- 底部状态栏：`5 条记录`、`已选择 0 条`、`已加载 5 条已知主机记录`

**我们**：是一个 620 宽弹层，列表 + 搜索 + 清空/导入/导出；**没有表格列**、没有刷新/重新信任/删除按钮组、没有底部状态栏。

## 6. 设置页（原生）
- 两栏：左侧分类（通用 / 终端 / 连接 / 文件 / 安全 / 备份与同步 / AI 助手 / MCP / 键盘快捷键 / 关于）
- 通用页行项：语言（English/简体中文/**繁體中文**）、外观（**跟随系统**/深色/浅色）、界面文字大小 小/标准/大、
  终端工具栏位置 左/右、标签方向 水平/垂直、显示标签编号、**后台终端输出提醒**（蓝/绿/黄说明）、
  界面字体（默认/选择）、开机自启、关闭窗口时（留在托盘/直接退出）、再次启动时（显示已有窗口/新建窗口）

**我们**：单列弹层，分区为 语言/外观/主机列表/终端/启动时打开/关于。
缺：分类导航、繁體中文、跟随系统、终端工具栏位置、后台输出提醒、界面字体、开机自启、托盘行为、再次启动行为。

## 7. 终端视图（原生）
- 标签在顶栏（见 1）
- 右侧**竖排图标栏**（约 11 个图标：分栏、终端、会话、时钟、网格、下载、密钥、监控、文件…）
- 终端正文区，底部无单独工具条（工具在右侧栏）

**我们**：标签在内容区；终端工具条在正文上方横排；**没有右侧竖排栏**。

## 8. 工作区页（原生，Round 171 追加观察）
- 标题 + 说明「保存常用的终端组合与布局，一次打开。」+ 右上「+ 新建工作区」
- 每个工作区卡片：名称 + 「N 个终端」+ 右上「▶ 进入工作区」+ ⋯菜单
- 卡片内含 **6 种布局模板缩略图**：1 列 / 2 列 / 3 列 / 主栏 + 右侧 / 主栏 + 底部 / 标签切换（选中的有描边）
- 模板网格下方是主机卡片（图标/名称/用户@地址:端口/分组·标签），可拖拽排序
- 新建工作区模态：临时连接 / 保存模板 两个分段；模板名称；搜索本机或 SSH 主机；
  左列 = 本机终端（CMD / Git Bash…）与主机（可勾选，分组折叠）；右列 = 终端布局 6 选 1 + 已选 N / 12 个 + 预览卡
  底部：取消 / 保存模板

**我们**：`workspacePage` 只有「会话列表 + 切换/关闭/关闭其他/重命名」，**没有工作区/模板/布局**概念。
差距：这是整个"工作区"页面的语义都不一样（上游=布局模板，我们=标签管理）。

## 9. 工作区内的终端（原生，主栏 + 底部布局）
- 顶栏左侧：`‹ 个人`（返回）+ 右侧「4/4 已连接」+「广播输入」+「布局」+ ×
- 上方主终端占满，底部 3 个横排终端（NAS / Oracle / 搬瓦工美国），每个有图标 + 标题行
- 右侧竖排图标栏（约 4 个图标 + ⋯）

**我们**：只有「单终端」与「分屏（左右两栏）」；**没有主栏+底部多行布局、没有广播输入、没有布局切换按钮**。

## 10. 顶栏标签的状态点（补充）
- 顶栏标签：图标 + 标题 + **状态点**（绿=就绪、黄=命令失败/需注意）+ ×
- 非活动有新输出时（设置里有开关「后台终端输出提醒」）用蓝/绿/黄区分：蓝=输出中、绿=结束/静默、黄=命令失败

**我们**：有琥珀色"未读"圆点（Round 165/166），但**没有三色语义**、也没有对应设置开关。

## 监控页：已补（Round 174，E1 实测通过）
- 侧栏新增「监控」`nav/monitor`（位于 工作区 之后）
- 页面：标题 + `monitor/toggle-detail`（简洁/详细）+ `monitor/sample`（立即采集）
- 第二行：搜索框 `monitor/search`、采集间隔 `monitor/every`（5s→15s→30s 循环 + 当前值）、保留时长 `monitor/keep`（1h→6h→24h）
- 列表：`monitor/host/<i>`、`monitor/meta/<i>`（未连接显示"未连接"）
- 采集实现：对**已连接且已信任**的主机执行 `cat /proc/loadavg; free -m; df -h /`，把原始输出截断展示

### 与上游仍有差距（诚实）
| 项 | 上游 | 我们 |
|---|---|---|
| 指标呈现 | CPU/内存/磁盘 百分比 + 进度条 + 网络收发 | 原始文本摘要（无百分比条） |
| 采集方式 | 常驻采集 + 面板/分组 + 图表 | 手动「立即采集」，无定时轮询、无图表 |
| 多面板 | 支持多面板（新建面板/停止监控） | 单列表 |

用例 `page.monitor` 已 **E1 通过**（进入监控页、切换详细、点采集间隔看到 15s/30s、保留时长按钮）。
