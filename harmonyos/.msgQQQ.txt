test(harmonyos/spec): 固定/折叠闭环用例 + schema 三处放行 before 断言

host.group-pin 从单向扩成闭环:
  建 G1 -> 建 G2(自然 G1 在前) -> 点 star 固定 G2 -> [步骤内断言] G2 在 G1 上方
  -> restart -> [步骤内断言] 仍 G2 在上方(固定状态持久化)
  -> 再点取消固定 -> [末尾断言] G1 回到 G2 上方(自然顺序恢复)

踩到的两个"测试自身"问题:
1. 断言位置: 一开始把"固定后 G2 在上"和"取消固定后 G1 在上"都塞进末尾 asserts,
   而末尾状态已取消固定 -> 两条互相矛盾必然失败。顺序类行为要放在动作之后立刻断言(步骤内 expect)
2. schema 三处都要放行: before 断言需要 $defs/assertion.properties 加 a/b,
   且 kind.enum 加 before; 只加前者时用例能跑过但 lint 报 schema 不合规
   => 用例绿了不代表基线合法

结果: host.group-pin / host.group-filter / host.group-collapse / host.manage => 4/4 PASS, lint 全绿
