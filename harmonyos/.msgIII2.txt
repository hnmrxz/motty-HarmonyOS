feat(harmonyos/ui): 命令面板列出主机(主机：<名称>  <地址>) + 用例 PASS

实现:
- paletteLabels(): 主机项排最前, 格式 "主机：<label>  <地址>"; 后面才是静态命令与"快捷命令："
- runPalette(): 认出 "主机：" 前缀 -> 按 label 找主机 -> openSession
- 为什么排最前: 面板列表高度有限, 放末尾会被滚出可视区(实测 dump 看不到, 用例失败)

用例 command.palette-hosts PASS: 建一台 pal-host -> 打开面板 -> 断言出现 "主机：pal-host"(且面板标题还在)
回归: command.palette / command.palette-keys / command.palette-esc / host.catalog => 4/4 PASS
  (command.palette 与 -keys 都假设"无主机时第0项是新建主机/第9项是设置", 空库下仍成立)

说明: 主机项进入面板后, 列表索引会随主机数变化 —— 以后写面板相关用例不要依赖固定下标,
  除非 spec 明确先清空主机(catalog/reset-hosts)
