feat(harmonyos/vnc): vnc 主机也能"打开"进 VNC 会话视图 + 用例 PASS

发现: VNC 会话面板早就存在(vnc/panel), 但只能从调试页进入, 且地址写死 127.0.0.1:5901;
  主机列表里 proto=vnc 的主机点"打开"走的还是 SSH 路径 —— 真实功能缺口

实现:
- 签名: startVnc(pwd, host='127.0.0.1', port=5901)
- 路由: openSession() 增加 h.proto==='vnc' 分支: 从内存凭据取密码、端口取主机记录(默认5900), 调 startVnc
- 复用既有 VNC 面板(画布/指针/键盘/剪贴板/DesktopSize)

用例 vnc.host-session PASS: 建 proto=vnc 主机(127.0.0.1:5901, 密码 secret) -> 点打开 ->
  进入 VNC 面板, drawn=N>0, canvas=WxH, 状态含 connected/auth

回归(VNC 夹具按需切换): vnc.session / vnc.adapt / ssh.connect-from-list / rdp.session-view => 4/4 PASS

关联经验: 路由分流(ssh/rdp/vnc)现在在 openSession() 里三段显式分支;
  新增协议必须在这里加一段, 否则会静默走 SSH 并报 "no credentials"
