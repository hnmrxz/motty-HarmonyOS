feat(harmonyos/ui): 新建/编辑表单支持协议选择(SSH/RDP/VNC) + 用例 PASS

实现:
- 表单控件 hostform/proto-ssh|rdp|vnc 三个 chip, 位于标签与分组之间
- @State formProto, 新建默认 ssh; 编辑时按已有 proto 回填
- 新建插入桶与编辑 update 都写入 proto
- 端口默认值按协议: SSH 22 / RDP 3389 / VNC 5900(用户填了端口则用用户的)

两个真实踩坑:
1) 改错了位置: 用字符串替换 'proto': 'ssh', 时匹配到别处, 插入桶仍是硬编码 ssh
   -> 表现"选了 RDP, 筛 RDP 却是 0 台, SSH 计数却 +1"; 改用行号定点替换后正常
   教训: 同类字面量出现多次时, 替换必须按行号/上下文定位, 并验证语义而不只是编译通过
2) 点 chip 会让输入框失焦: 先输入 label/address 再点协议 chip, 已输入内容被清掉,
   提交时 label 为空 -> 静默失败(submit() 在 label 为空时直接 return)
   用例改成先选协议、再输入, 并写进注释

用例 host.proto-filter PASS: 建 SSH/RDP/VNC 三台 -> RDP chip 只剩 pf-rdp -> VNC chip 只剩 pf-vnc
  -> 全部协议三台都回来
回归: host.manage / host.form-chips / host.form-validation / hosts.search => 4/4 PASS
