fix(harmonyos/ui): 批量删除必须二次确认(真实安全缺口)

问题: 全选后点"批量删除"直接删除, 没有确认框。官方语义是
  删除选中的 %d 台主机？此操作无法撤销。(host.deleteDesc); 单台删除有确认、批量却没有 -> 误删风险

现在:
- 点批量删除 -> askDeleteSelected(): 复制选中 id 到 deleteIds, 弹确认框(不再直接删)
- 确认框文案用真实台数: 删除选中的 2 台主机？此操作无法撤销。
- 确认 -> 逐台删 hosts + known_hosts + 保险库口令(与单台同一套语义), 再刷新
- 取消 -> 清空 deleteIds, 数据不动
- 单台删除行为不变(仍走 deleteIndex 分支)

用例 host.batch-delete(pcOnly) PASS:
  建2台 -> 全选 -> 批量删除 -> 断言确认框出现"删除选中的 2 台主机" -> 取消(两台还在)
  -> 再删一次 -> 确认 -> 断言回到空态、两台都不再出现

回归: host.batch-delete / host.manage / host.form-chips / snippets.crud => 4/4 PASS

  => "改了但没生效"必须靠用例确认, 不能只读代码
